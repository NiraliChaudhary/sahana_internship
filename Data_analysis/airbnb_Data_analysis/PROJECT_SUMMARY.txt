ANALYSIS TECHNIQUES EXPLAINED
================================================================================

DATA CLEANING METHODOLOGY:
  1. Duplicate Detection: Removed exact duplicates + ID-based duplicates
  2. Missing Value Strategy:
     - Temporal data (last_review): Keep as NaT
     - Zero-count data (reviews_per_month): Impute 0
     - Categorical (host_name): Impute 'Unknown'
     - Numeric: Median imputation (robust to outliers)
  3. Outlier Detection: IQR method (Interquartile Range)
     - Price: Removed 2,972 outliers (1.5× IQR from Q1/Q3)
     - Minimum Nights: Removed 6,185 outliers
     - Total: 9,157 rows (18.7%) removed
  4. Data Type Correction:
     - Datetime parsing for temporal fields
     - Categorical enforcement for text fields
     - Numeric coercion where appropriate
  5. Feature Engineering:
     - price_per_min_night: Effective price metric
     - estimated_occupancy_rate: Revenue indicator
     - has_reviews: Activity status
     - host_experience: Host profiling
