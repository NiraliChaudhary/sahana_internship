Feature & Algorithm Insights

🎯 Optimal Kernel Selected: LINEAR kernel works best for this dataset, indicating linear decision boundaries in the medical features.
📊 Feature Scaling Impact: StandardScaler was essential - it ensured all 30 medical measurements contributed equally to the decision boundary, preventing high-range features from dominating.
🔍 Support Vectors: The model uses only support vectors (boundary points) for prediction, making it memory-efficient and interpretable.
⚙️ Hyperparameter Optimization: GridSearchCV tested 96 parameter combinations (4 kernels × 4 C values × 6 gamma values) to find the optimal configuration with 98.02% cross-validation accuracy.

Why SVM Succeeded Here

1️⃣ High-Dimensional Data: 30 medical features - SVM handles this well through kernel trick and doesn't suffer from curse of dimensionality like some algorithms.
2️⃣ Clear Separability: Medical measurements naturally separate benign from malignant cases, and SVM excels at finding optimal separating hyperplanes.
3️⃣ Robust Margins: Maximum margin principle ensures the decision boundary stays far from training points, improving generalization to new patients.
4️⃣ Interpretability: Support vectors identify the most informative cases, helping clinicians understand which features matter most.
